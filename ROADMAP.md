# Roadmap

## Done
- [x] Metadata: ComicVine and Metron search, covers, issue lists, scheduled refresh
- [x] Magazines: issue schedule from release frequency
- [x] Indexers: Newznab, Torznab, Prowlarr; RSS sync; automatic + interactive search
- [x] Decisions: title/issue matching, quality profiles with upgrades, blocklist, seeders
- [x] Download clients: qBittorrent, Deluge, Transmission, SABnzbd, NZBGet; queue; remote path mappings
- [x] Import: rename, move/hardlink, ComicInfo.xml, failed download handling + re-search
- [x] Library import, rename, file management, title edit/delete
- [x] Connections: Komga, Kavita, Discord, Webhook
- [x] eBooks: authors and books from Open Library / Google Books; book release matching and import
- [x] Magazine details from Wikidata or ComicVine
- [x] Forms/Basic login, API key, iCal feed, health checks, scheduled tasks

## Next

- [ ] Issue packs (one release containing many issues)
- [ ] Manual import of a folder of loose downloads

- [ ] Logs page and backups of `/config`

- [ ] OPDS feed
